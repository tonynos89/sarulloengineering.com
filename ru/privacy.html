Файлы cookie и аналитика

Сайт не использует файлы cookie, инструменты аналитики или профилирования и ничего не загружает со сторонних сервисов: шрифты, изображения и скрипты размещены на самом сайте. Браузер сохраняет только выбранный вами язык, чтобы при следующем посещении показать нужную версию; эта информация остаётся на вашем устройстве и никуда не передаётся.

Хостинг

Сайт размещён на GitHub Pages (GitHub, Inc.). Как и любой веб-сервер, GitHub может записывать технические данные о посещениях, например IP-адреса, в целях безопасности и для работы сервиса. GitHub обрабатывает эти данные в соответствии со своей политикой конфиденциальности.

Электронная почта

Если вы мне напишете, я использую ваш адрес и присланную информацию только для ответа и, по вашему желанию, для начала сотрудничества. Правовое основание: ответ на ваш запрос (ст. 6(1)(b) GDPR). Я храню сообщения столько, сколько необходимо для нашего общения, и не передаю их третьим лицам.
